*notemode.txt*  Markdown のノートを専用タブで書くためのプラグイン

==============================================================================
目次                                                        *notemode-contents*

  1. 概要 ..................................... |notemode-intro|
  2. :Note .................................... |:Note|
  3. gf ....................................... |notemode-gf|
  4. 設定 ..................................... |notemode-config|
  5. Lua API .................................. |notemode-api|

==============================================================================
1. 概要                                                        *notemode-intro*

|notemode-config| の `dir` (既定 `~/notes`) 配下の Markdown をノートとして扱う。

ノートのディレクトリ配下の `.md` を開くと、ノートモードの外でも自動的に
ノート用バッファになる。ノート用バッファでは:
  - `gf` でその行に書いたノートへ飛べる (|notemode-gf|)
  - 'wrap' と 'linebreak' を有効にする
  - `autosave` が有効なら編集のたびに保存する
  - 保存時に親ディレクトリがなければ作る

==============================================================================
2. :Note                                                                *:Note*

:Note
    ノートモードの開閉を切り替える。

    入るときは専用のタブを開き、その作業ディレクトリをノートのディレクトリに
    移して `index` のノートを開く。何も開いていない空のタブ (`nvim +Note`
    など) ではそのタブをそのまま使う。

    抜けるときはノートをすべて保存してタブを閉じる。最後のタブなら、
    `nvim +Note` で起動したときだけ `:confirm qall` し、それ以外は nvim を
    閉じずにタブを空のバッファと元の作業ディレクトリに戻す。

==============================================================================
3. gf                                                             *notemode-gf*

ノート用バッファの `gf` は、その行に書いたノート名へ飛ぶ。次の順に探す:
  1. 行全体をノート名として (先頭の `- ` `* ` `1. ` `[ ]` などは除く)
  2. カーソル下のファイル名 (|<cfile>|)

名前はファイル名 (拡張子はあってもなくてもよい) か、ノートのディレクトリ
からの相対パス。完全一致がなければ大文字小文字を区別せずに探し、同名が
あれば浅い階層のものを優先する。

どれも見つからなければ、行全体の名前で新しいノートを開く (保存するまで
ファイルは作られない)。index にノート名を 1 行ずつ並べておけば、そこから
`gf` で飛べる。

==============================================================================
4. 設定                                                       *notemode-config*

`require("notemode").setup(opts)` に既定値との差分を渡す。既定値: >lua

    require("notemode").setup({
      dir = "~/notes",
      -- :Note で開くノート
      index = "index.md",
      autosave = true,
      -- 新しく開くノートの中身。{{title}} {{date}} {{time}} が置換される
      templates = {
        note = "# {{title}}\n\n",
        index = "# Index\n\n",
      },
      -- ノートバッファ内のキーマップ。false で無効、mappings = false で全部無効
      mappings = {
        goto_file = "gf",
      },
    })
<
==============================================================================
5. Lua API                                                       *notemode-api*

require("notemode").setup({opts})                            *notemode.setup()*
    |notemode-config| を参照。

require("notemode").toggle()                                *notemode.toggle()*
require("notemode").enter()                                  *notemode.enter()*
require("notemode").leave()                                  *notemode.leave()*
    ノートモードの開閉 / 入る / 抜ける。

require("notemode").statusline()                        *notemode.statusline()*
    ノートモードのタブにいれば "NOTE"、そうでなければ "" を返す。
